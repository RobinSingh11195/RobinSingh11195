### 🏃 Fitness Data Tracker
**Problem Statement No. 77**

A Python 3 console application for recording and reviewing daily fitness activity.

| Feature | Description |
|:--|:--|
| Daily records | Stores steps and calories burned |
| Step goal | Tracks progress towards 10,000 steps |
| Activity summary | Average steps, total calories and best day |
| BMI calculator | Calculates BMI and displays its category |
| Data visualisation | Daily step-count bar chart using Matplotlib |

**Built with:** Python 3 · Lists · Functions · Matplotlib

<sub>Records are stored in memory while the application is running. Permanent storage is not included.</sub>
